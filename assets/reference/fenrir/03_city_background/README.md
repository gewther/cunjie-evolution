现有三层结构的职责：
- Far：远景天际线和空气透视。
- Mid：建筑正立面、商铺和街区轮廓。
- Near：道路、车道线、车辆、路灯和护栏，保持与接地平面一致。

## 推荐场景要素

- 中低层住宅与商业建筑交错，保留楼层、窗户、阳台、屋檐等真实尺度线索。
- 电线杆、架空线、路灯、护栏和车辆为重要尺度锚点。
- 雨后柏油路反射环境灯光，但反光强度应受路面粗糙度控制。
- 远景降低对比度和细节密度，近景保留道路纹理、积水和小型杂物。
- 保留生活化暖色窗灯，芬里尔的青色自发光只作为局部主光源。
