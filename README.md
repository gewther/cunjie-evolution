# 寸界 · Evolution（AJ6 屋顶场景 & 芬里尔雨夜猎场整合版）

- **在线游玩（GitHub Pages）**：https://gewther.github.io/cunjie-evolution/

## 主要内容
- **主线三幕剧情模式**：支持 AJ5 Aqua / AJ6 UNC（含 960×1536 高清分帧）/ 乔丹青黄鞋款，以及屋顶夕阳、屋顶夜景、雨夜木地板、午后卧室、雨夜卧室、原版卧室等多场景切换。
- **芬里尔 · 蓝调雨夜猎场**：3 波次猎场模式 + 一键切换无尽自由、狂躁蓄能与 `CORE OVERDRIVE [F]` 核心过载、湿路拖碾、领跑截击、撤离点清剿、原创狂傲少年感台词与路面小人短呼气泡。
- **高清渲染与自定义导入**：支持 1080p / 2K / 经典像素清晰度切换、自定义 1024×1024 角色图集与 `.cunjie-skin.json` 皮肤包导入。
- **芬里尔城市尺度场景（实验分支）**：新增远景/中景/近景三层蓝调城市 SVG 与有限视差，保持现有动作、碰撞和三波猎场逻辑不变。

## 目录结构
- `src/`：玩法、手感、接地视觉、皮肤运行时与芬里尔模块源码
- `tools/`：构建、打包与自动化回归测试脚本
- `dist-release/game/`：精简网页发布版（GitHub Pages 部署目录）

> **部署安全**：GitHub Pages 是公开站点。工作流默认跳过部署；只有仓库变量 `ALLOW_PUBLIC_GITHUB_PAGES=true` 时才允许发布。不要把它当作私密站点托管方案。
